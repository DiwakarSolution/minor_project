## Run locally

1. clone you github repository 
2. Open `index.html` in a browser.
3. No build tools, package installation, or server are required.

## Customize your projects
##  If project add the time
- Open `index.html` and update the project cards:
- Replace `Your Project Name` and the descriptions.
- Update the technology tags.
- Replace the GitHub profile URLs with each project's repository URL.
- Replace the “Add live demo URL” text with an anchor link when a live demo exists.
- Replace SVG artwork in `assets/` with your own screenshots if desired.

The first portfolio card links to the existing `DiwakarSolution/port-folio` repository. Other cards link to the GitHub profile until their individual repository URLs are supplied.

## Technologies

- HTML5 semantic elements
- CSS3 custom properties
- CSS Grid and Flexbox
- Responsive media queries
- Focus-visible and reduced-motion support
